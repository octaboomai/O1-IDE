Download help

Last updated: October 2026

o1 IDE is free and open source. The installers are built automatically by our GitHub Actions pipeline and published on the Releases page.

Windows builds are not code-signed. We applied to the SignPath Foundation open-source signing programme but were not accepted, so the Windows installer ships unsigned. That is what triggers the browser and SmartScreen warnings below — it does not mean the file is unsafe.

If Chrome / Edge blocks the download

Browsers warn about files that “aren't commonly downloaded”. Open the download list (Ctrl + J in Chrome/Edge), then choose Keep — or use the PowerShell method below.

Download with PowerShell (recommended if the browser blocks it)

Open a Windows PowerShell window and paste these two lines:

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-WebRequest -Uri "https://github.com/octaboomai/O1-IDE/releases/download/v0.1.0/o1-ide-0.1.0-windows-x64.exe" -OutFile "$env:USERPROFILE\Downloads\o1-ide-0.1.0-windows-x64.exe"

The file lands in your Downloads folder. Then double-click it to install.

If SmartScreen warns when you run it

Windows SmartScreen warns about any app without an established download reputation. To continue:

  • Click More info, then Run anyway.
  • If your organisation blocks unsigned apps by policy, ask your IT team — that is a policy setting we cannot override.

Verify what you downloaded

Every release lists a SHA-256 digest next to each file. To check yours matches:

Get-FileHash "$env:USERPROFILE\Downloads\o1-ide-0.1.0-windows-x64.exe" -Algorithm SHA256

Compare the output with the digest shown on the Releases page. If they match, the file is exactly what our build produced.

Builds come from this repository. Every installer is produced by our public CI from the tagged commit — see Actions.

Linux

Linux installers are not affected by these warnings. Download the .deb or .AppImage from the Releases page and follow the instructions there.
