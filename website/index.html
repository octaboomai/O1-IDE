Features

Everything a robotics engineer needs

Built on Eclipse Theia. All 8 features work out of the box — no plugins to install, no configuration files to write.

01
C++ + Python LSP
clangd bundled in the app. pyright included. IntelliSense, go-to-definition, and diagnostics work on first open.
02
Attach-to-node debug
launch.json auto-written in every workspace. Attach to running ROS nodes via GDB (C++) or debugpy (Python).
03
URDF / Xacro 3D preview
Opens split-right when you open a .urdf or .xacro file. Three.js renderer with orbit camera, wireframe, and axes.
04
.msg .srv .action syntax
TextMate grammar + autocomplete for all ROS primitive types. The editor understands your interface files.
05
colcon + CMake tasks
13 pre-built tasks: colcon build, colcon test, rosdep install, cmake configure, ros2 doctor, and more.
06
One-click toolchain
ROS 2 detection on startup. Missing tools shown with install buttons. Runs apt on Ubuntu, winget on Windows.
07
ROS topic viewer
Live topic list via rosbridge. Subscribe and see message data in real-time. Works with any ROS 2 distro.
08
Project templates
5 ready-to-fly starters: PX4 Quadcopter, ArduPilot Fixed-Wing, ROS 2 Ground Robot, Jetson Vision, RPi Bridge.

Getting started

Up and running in 3 steps

01
Download and install
Pick your platform above. On Ubuntu, double-click the .deb or run dpkg -i o1-ide.deb. On Windows, run the .exe installer.
02
Open your workspace
Launch o1 IDE and open your ROS 2 workspace folder. The IDE detects ROS 2, clangd, and pyright automatically and shows what's missing.
03
Start building
Open a .urdf file to see 3D preview. Run colcon build from the task runner. Connect to your drone's rosbridge to see live topics.
