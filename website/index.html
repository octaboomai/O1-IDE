01 / Diagnosis

The setup is harder than the code.

Robotics tooling was designed for a Linux workstation. Everyone else spends their first week on configuration instead of robots.

1

ROS 2 assumes Linux.

DDS discovery, build flags and the toolchain all assume a POSIX environment. Off that path, nothing behaves predictably.

2

Windows developers live in WSL2, half-configured.

Editing on Windows, building in Linux, and nothing bridging the two. GUI tools lag, hardware passthrough is fragile.

3

Setup outlasts the code.

Sourcing scripts, workspace overlays and build flags take longer to get right than the node you actually wanted to write.

One command, or one click.

# download and install the Debian package
wget https://github.com/octaboomai/O1-IDE/releases/download/v0.2.0/rovant-desktop_0.2.0_amd64.deb && sudo apt install ./rovant-desktop_0.2.0_amd64.deb
# download, make executable, run

[ NOTICE ] Windows builds are unsigned. SmartScreen may prompt — click More info → Run anyway. Code signing certificates are being provisioned for the next release.
05 / Open source

Apache 2.0, no lock-in.

Rovant is released under the Apache 2.0 licence and built on Eclipse Theia. Read it, fork it, ship your own build — there is no commercial tier gating the editor. Source, issues and roadmap live on GitHub.

Public beta limitations
  • Windows: requires WSL2 with an Ubuntu 22.04 LTS distribution. ROS 2 Humble must be installed inside it — the Toolchain panel can do this, but it needs winget.
  • Linux: built and tested on Ubuntu 22.04 LTS, x86_64.
  • ROS 2 distro: Humble only. Jazzy and Rolling are not supported yet.
  • No IntelliSense yet: no completion, go-to-definition or inline errors.
  • No debugger yet: the launch configurations were removed in 0.1.1 because they failed with a timeout.
  • Unsigned builds: SmartScreen warnings on Windows until certificates arrive.
  • Architecture: x86_64 only; no ARM builds yet.
